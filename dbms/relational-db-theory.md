# Relational Model

## Relation,Tuple,Attribute 

* Relation - refers to a table
* Tuple - refers to a row
* Attribute - refers to a column of a table.

## Keys

* Superkey - Identifies all possible combinations that uniquely identify rows
* Candidate key -	Identifies minimal combinations that uniquely identify rows
* Primary key -	The candidate key selected as the main identifier
* Alternate key -	Candidate keys not selected as the primary key
